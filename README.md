# project
idk

Бот на telebot "умный холодильник".

Когда пищевые отходы попадают на полигон, они разлагаются без доступа кислорода. В таких условиях бактерии выделяют не углекислый газ, а метан (CH4).  
Метан - один из самых опасных парниковых газов: в краткосрочной перспективе он в десятки раз эффективнее удерживает тепло, чем CO2.  
По оценкам межправительственной группы экспертов по изменению климата (МГЭИК), на пищевые отходы приходиться значительная доля антропогенных выбросов метана.
При этом Агенство по охране окружающей среды США установило, что одни только пищевые отходы ответственны примерно за 58% выбросов метана со свалок.  
Помимо метана, при разложении органики на свалках также выделяется СО2, а на полигонах из пищевых отходов образуется токсичный фильтрат, который загрязняет почву и грунтовые воды.
  
Идея бота:
Человек вносит все купленные им продукты вместе со сроком годности в бота, а тот в свою очередь записывает это в базу данных.
Каждое утро бот проверяет дату и если обнаруживает продукты, у которых скоро истекает срок годности, отправляет пользователю уведомление об этом.  
Цель бота:
Сократить количество пищевых отходов, научить людей заботиться о природе и рационально подходить к потреблению ресурсов планеты.
